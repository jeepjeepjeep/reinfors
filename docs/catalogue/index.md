# Catalogue

Use the catalogue to choose a supported composition without relying on hard-coded lists elsewhere
in the documentation.

- [Games](games.md) covers decision modes, chance, information, action and observation spaces,
  rewards, encoders, and ecosystem adapters.
- [Algorithms](algorithms.md) maps policies or solvers to learners, batch types, inference outputs,
  examples, and source papers.
- [Compatibility](compatibility.md) is the authoritative game-by-algorithm matrix.

After selecting a composition, use its linked example or return to the
[training guide](../guides/training.md).
