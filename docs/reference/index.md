# Reference

These pages state the exact boundary contracts needed when implementing a training loop or
extension. Begin with [getting started](../getting-started.md), then read the inference contract
before implementing a real callback; the remaining pages are references for exact shapes, fields,
and boundaries.

- [Inference contract](inference-contract.md): callback inputs, outputs, routing, and legality.
- [Batch formats](batch-formats.md): named fields for each learner family.
- [Glossary](glossary.md): collection, game-state, network, lifecycle, and search terms.
- [Telemetry fields](telemetry-fields.md): collection metrics and episode records.
- [Python API](python-api.md): module map and source of signature truth.
- [Troubleshooting](troubleshooting.md): common callback, stream, build, and learning failures.
- [Current boundaries](limits.md): deliberately unsupported or bounded semantics.
- [References](references.md): sources for the algorithms, encodings, and validation targets.
